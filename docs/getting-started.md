# Getting started

Run one command in the project you want to prepare:

```bash
npx sdd-agentic-flow init
```

In a real terminal, guided onboarding configures the project, installs the `full`
pack for you by default, creates project context, and runs `doctor`. Press Enter
to choose the recommended setup, review it once, and apply it. Choose **Customize setup** only
when you need a different pack, scope, skill targets, or project sharing. Use
`--non-interactive` in scripts and CI.

Existing `core` installations remain unchanged until you explicitly change setup.
For install scopes, custom packs, and collision handling, see
[installation](installation.md).
