# Global guidance

Treat approved specs and the configured project policy as the source of truth.
Separate confirmed facts, assumptions, proposals, and unknowns. Inspect existing
project conventions before proposing code. Scope work to the selected feature or
task; report design, requirement, scope, or breaking drift for reconciliation.

Every handoff names the artifact changed, evidence collected, checks not run, risks,
and the next human decision when one is needed.
